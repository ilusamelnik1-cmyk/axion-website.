# AXION website

Готовый адаптивный сайт-визитка AXION на HTML, CSS и JavaScript.

## Что внутри
- Русский и румынский языки (переключатель RU / RO)
- Адаптация под телефон, планшет и компьютер
- Разделы: услуги, портфолио, подход, процесс, контакты
- Без серверной части и платных библиотек

## Перед публикацией обязательно замени
1. В `index.html` найди `hello@axion.md` и замени на свой рабочий email.
2. Замени ссылки Telegram и WhatsApp на свои реальные ссылки.
3. В разделе «Портфолио» замени демонстрационные CSS-иллюстрации на реальные скриншоты своих работ. Не публикуй чужие проекты как свои.
4. Проверь формулировки услуг и не обещай сертификацию или выполнение работ, для которых нужна лицензия.

## Публикация через GitHub Pages
1. Войди в GitHub и создай новый публичный репозиторий, например `axion-website`.
2. Загрузи в корень репозитория файлы `index.html`, `style.css`, `script.js` и `README.md`.
3. Открой Settings → Pages.
4. В разделе Build and deployment выбери `Deploy from a branch`, ветку `main` и папку `/ (root)`, затем нажми Save.
5. Через несколько минут GitHub покажет адрес сайта в разделе Pages.

Пароль или токен GitHub никому не отправляй. Для загрузки файлов достаточно интерфейса GitHub в браузере.

## Контакты
Пока используются заглушки. Замени их перед тем, как делиться сайтом с клиентами.
